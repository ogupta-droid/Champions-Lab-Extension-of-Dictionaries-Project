# Champions-Lab-Extension-of-Dictionaries-Project
# LLM Project

Champions Lab is an interactive football website built from my Python dictionary project using Codex.

## Key Features and Extensions

- **Team comparisons:** Compare clubs using their statistics.
- **Adjustable power rankings:** Change the importance of different stats to see how rankings change.
- **Club management:** Add, edit, and delete clubs.
- **Match simulations:** Generate possible outcomes that are clearly labeled as simulations.
- **Player explorer:** Explore players and their Champions League achievements.
- **Interactive design:** Charts, player images, and scroll animations make the website more engaging.

## Challenges I Ran Into

My website originally used a localhost link, which stopped working when the server on my Mac wasn't running. With help from Codex, I published the website online and made it public so my teacher could access it even when my computer was off.

## What I'd Improve With More Time

I would connect the website to a reliable football data source so stats update automatically. I would also improve the mobile layout and test more features to catch bugs.
